# Motune のサポートと規約

App Store が必須とする 2 枚（サポート・プライバシーポリシー）を置く場所。
**アプリのソースは別のリポジトリ**（非公開）で、ここには HTML になる文書しか
置かない。

```
index.md        入り口
support-ja.md   サポート        日本語
support-en.md   Support         英語
privacy-ja.md   プライバシー     日本語
privacy-en.md   Privacy Policy  英語
```

## 直すときは

**本文の出所は本体リポジトリの `site/` にある。** あちらはコードと突き合わせて
書いてある（通信の API が 0 件であること、HealthKit が心拍を読んでいないこと
などを確認済み）。**ここだけ直すと食い違う**ので、`site/` を直してから移すこと。

## 連絡は Issues で

利用者からの連絡窓口を兼ねている。素っ気ない 1 枚を置くより、実際に書き込める
場所があるほうが伝わる。
